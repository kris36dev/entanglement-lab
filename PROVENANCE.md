# Provenance and scope

Created in September 2026 as a new portfolio implementation based on quantum-computing lectures the portfolio owner studied in summer 2023. The seed 2023 is only a reproducibility setting. This is not a claim that this software was written in 2023.

Implementation, tests, experiments, and documentation were developed with AI assistance in ChatGPT. The repository owner should review and understand the algorithms before presenting the work as part of an application or interview.

The lecture PDFs and slide images are not distributed. SOURCES.md maps the project to the supplied course material and public references. The MIT license covers the original repository code and documentation, not the source lectures or linked third-party material.

All numerical outputs are local classical simulations. No quantum hardware, real customer data, commercial deployment, or measured business impact is represented.
